# Airsoft Domination Game

Este Projeto fará parte de uma rede de jogo de Airsoft em que o objetivo será vários tipos de jogos e dispositivos se comunicarem num só ponto podendo assim ampliar a jogabilidade e conseguirmos extrair novas emoções.

## Módulo Domination
O objetivo deste módulo é tarnsformar uma área específica num capo de batalha autêntico entre equipas um competição "sangrenta" de obter o maior número de pontos.


### Funcionamento e regras
#### Regras
A baliza será iniciada com o seu estado neutro e com a pontuação zerada para ambas as equipas.
Para conquistar a baliza neste estágio apenas basta algum membro de uma equipa pressionar o botão da sua equipa e esperar até que a baliza mude para a sua cor, caso seja atinjido o jogador deverá se dar como morto imediatamente, terá que contar apenas com os seus membros de equipa para o protegerem.
Após a conquista a outra equipa para puder conquistar a baliza terá primeiro que neutralizar para depois conquistar mas atenção esta fase tem de ser muito bem planeada pois caso desista da neutralização ou seja abatido antes da neutraliazação irá pontuar para a equipa da baliza conquistada.
O jogo não conta com limite de tempo.

#### Pontuação
Conquista da baliza = 100 pontos
tentativa falhada da baliza = 50 pontos


### Funcionamento
O dispositivo deverá de ser conectado á energia.
Após o seu arranque irá ouvir 3 apitos, apos os mesmos o dispositivo fica em modo stand-BY á espera que os 2 butões sejam pressionados ao esmo tempo para assim fica ativo e em estado neutro.
